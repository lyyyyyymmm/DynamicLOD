# 项目概览

- 论文类型：应用型图形学/WebGIS 方法论文
- 研究对象：Web 3D Tiles 运行时 LOD 调度
- 中文题目：面向尾部帧时约束的 Web 3D Tiles 预测式动态 LOD 调度方法
- 英文题目：Predictive Dynamic LOD Scheduling for Web 3D Tiles under Tail Frame-Time Constraints
- 核心问题：在 P95 帧时不超过 33.33 ms 的约束下，能否结合短期负载预测、公开请求反馈和交互状态，降低超限率并控制视觉质量损失与调度振荡。
- 论文结构：摘要、引言、相关工作、方法、实验设计、结果、讨论、结论。
- 当前阶段：S4 中英文初稿同步；正式结果尚未采集。
- 证据边界：工程冒烟记录不得写作性能结论；大雁塔案例在授权完成前不得形成推广性结论。
