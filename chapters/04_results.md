# 5 实验结果

> 归档说明：本拆分文件保留结果章节的占位结构。当前冻结设计以 D-031 / protocol v2.3.6 为准：桌面端正式效果检验仅纳入 PC-A 与 PC-B 的本地服务器 D1/S3、D2/S3 pressureBurst 队列；Android-A 只作为可运行性、遥测完整性和低压力边界证据，不进入正式效果聚合。

本节围绕尾帧预算约束、视觉质量代价、控制稳定性、组件作用和同源数据集外部验证组织证据。当前 D-031 正式桌面实验尚未采集，C1—C4 与 C7 均处于 `UNMEASURED` 状态，C5 受数据授权限制，因此以下内容只规定结果回填后的比较关系、统计量和解释边界，不构成任何性能、质量或泛化结论。各项判断须以 PC-A 与 PC-B 上完成的 D-031 本地服务器、方法内随机顺序配对实验为依据；缺失运行、无效运行、远程/LAN 页面、Android 诊断运行和不完整六方法配对块不得用于支持主张。

## 5.1 尾帧预算约束

[待正式实验回填] 正式矩阵完成后，本小节将按设备、数据集和场景报告 fixed SSE 8、fixed SSE 16、Cesium dynamic SSE、reactive、PI 与 proposed 六种方法的 P95 控制窗口超出 33.333 ms 预算的比例。D-031 主矩阵限定为 PC-A 与 PC-B 的 D1/S3、D2/S3 pressureBurst，本地服务器页面来源，固定随机种子 `20260823`，每台桌面设备 120 次运行。描述性统计从 `descriptive_violation_rate.csv` 回填每组有效运行数、中位数、第一四分位数和第三四分位数，并同时交代完整六方法配对块数量。总体差异由 Friedman 检验的统计量与 p 值刻画；预设的 proposed—reactive、proposed—Cesium dynamic 和 proposed—PI 配对比较须回填 Wilcoxon 符号秩统计量、原始 p 值、Holm 校正 p 值、Hodges—Lehmann 配对差估计、配对秩二列相关效应量及配对差中位数的 95% Bootstrap 置信区间。只有效应方向、区间估计和多重比较校正结果共同支持时，才能对 C1 作方向性陈述；否则应如实报告差异不确定、无统计支持或设备/数据集分层不一致。

## 5.2 质量—性能权衡

[待正式实验回填] 本小节将把尾帧预算表现与时间加权 SSE、六个规范视角的窗口 SSIM 以及可见瓦片几何误差对应起来。每个设备与场景均需回填 proposed 及各基线的有效样本量、中心趋势和离散程度，SSIM 计算以 SSE 4 渲染为同视角参考，并明确图像采集、配准和无效截图排除规则。视觉质量判断采用预先声明的 0.02 非劣界值，回填相应的配对差、置信区间和非劣判定；在置信区间未满足预设判据时，不得以平均值接近或个别视角相似替代非劣证据。C2 只有在尾帧约束证据与视觉质量证据均完整时才可更新，且“预算违例减少”不能被直接解释为“无质量代价”。

## 5.3 控制稳定性与恢复

[待正式实验回填] 控制稳定性将针对 reactive 与 proposed 回填每分钟 SSE 切换次数、相邻反向切换次数和交互结束后的恢复时延，并按设备、数据集、场景及重复编号保持配对。结果叙述应同时给出分布统计和配对差，区分减少无效振荡与延迟质量恢复这两种可能并存的现象。若 proposed 的切换或反转较少，但恢复时延越过预设容忍范围，结论应保留该权衡；若不同设备上的方向不一致，则分别报告而不合并为稳定性优势。C3 还须与无稳定性保护消融的结果相互印证，缺少该消融时只能呈现测量值，不能把观察到的切换差异归因于滞回、冷却时间或连续资格判定。

## 5.4 消融实验

[待正式实验回填] 消融分析冻结为 PC-A 的 D1/S3 pressureBurst 条件，独立于主六方法聚合，分别比较完整 proposed 与 no-prediction、no-request、no-interaction 和 no-stability 变体。回填内容至少包括 P95 窗口预算违例率、时间加权 SSE、请求队列峰值与面积、每分钟切换次数、反转次数及恢复时延，并保留相同重复编号下的配对关系。预测模块的作用只能由 no-prediction 对照支持，请求反馈的增量价值只能由 no-request 对照支持，交互感知与稳定性保护也须由各自删减变体的对应指标支持。单个指标出现有利方向不足以确认组件贡献；C4 的更新还要求效应量和不确定性区间与预设比较一致，且不得把主实验差异直接归因于未经消融支持的模块。
